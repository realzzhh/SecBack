# 主密码与恢复码

更新：2026-11-26。

## 已经忘记主密码

若此前设置过恢复码，登录页选择「主密码忘了？用恢复码打开」，输入完整恢复码。验证成功后必须设置新的主密码才能进入主界面；取消或系统返回会撤销恢复会话并锁定。

没有恢复码时，尝试您仍记得密码的旧加密备份。既无主密码又无可用恢复码时，应用没有后门或管理员解锁通道。恢复码不能找回已被删除的密库文件。

## 提前设置恢复码

解锁后在「更多」或桌面菜单中选择设置恢复码，输入当前主密码。将生成的 32 个字符抄写到纸上，按界面要求核对最后 8 位。恢复码有 160 位随机输入，使用 Crockford Base32；容忍大小写、空白、短横及 O/0、I/L/1 混淆，不会容忍任意字符顺序错误。

恢复码写盘成功后即生效，关闭展示不会撤销它。重新生成会替换当前库的恢复槽，旧备份仍可能使用旧恢复码。请保护所有加密备份及对应凭据。

## 格式与改密

未启用恢复码的新库使用 v1。启用时升级到 v2，引入随机数据密钥，主密码和恢复码分别包装同一密钥。当前实现改主密码仍会保存并重写整个加密文件；没有只更新头部的优化。

Rust 读取 v1 和 v2。冻结的 C++ 参考实现仅支持 v1。查看其他实现是否支持 v2 后再交换文件。

新主密码为 6～1024 个字符；已有短密码仍可登录。请使用您能长期保管的独立口令，恢复码与密库分开放置，并定期导出独立加密备份。

历史设计方案见 archive/20261125/主密码忘了怎么办.md；其中旧估算和设想不作为当前操作说明。
