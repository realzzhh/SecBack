# Android 安装与备份

更新：2026-11-26。当前包名 com.secback.vault，版本来自根 package.json；arm64-v8a，最低 Android 7 / API 24。本轮验证设备是 Android 17，其他版本仍需兼容性覆盖。

## 安装与升级

将 delivery/android/SecBack-Android-arm64.apk 复制到手机，用文件管理器安装。系统可能要求允许该来源安装应用。升级请覆盖安装，保持相同签名；卸载或清除数据会删除应用私有密库。

密库使用系统提供的应用私有目录，保留既有 files/sec.properties 路径。系统云备份和设备迁移已关闭；请自行导出备份。

## 备份

1. 解锁后进入「更多 → 导出加密备份」，宽屏也可使用顶栏导出入口。
2. 在系统保存界面选择文件位置及新文件名，确认保存。
3. 应用回读并逐字节核对成功后才提示备份完成，并显示目的位置与时间。
4. 将文件放到独立设备，使用桌面版「文件 → 从另一台机器导入」输入导出时的主密码，核对预览。保留先前版本的备份。

导出保持密文和原恢复槽。手机现在可通过“导入”从系统文件选择器选取加密备份，输入该备份的主密码，检查预览后确认合并。应用会读取 content URI 的密文快照，不需要把文档 URI 转换为普通路径。新装应用需先创建或解锁本地密库，再导入备份；只恢复项目与账户，不替换本地主密码或恢复码。不要为验证而卸载或清空应用，应先核对独立备份。

## 使用

每项最多三套账户。编辑时密码默认遮盖，新增/编辑的保存和取消位于顶部；只有表单内容滚动。有未保存修改时返回会询问是否放弃。

复制通过系统剪贴板，标记敏感内容；前台约 60 秒后、或离开时尝试清除仍属于本应用的内容。切入后台会锁定；导出文件选择流程临时保留会话，取消或返回后可继续操作。

截图/录屏变黑是应用保护策略，在部分厂商系统上密码输入也会触发额外保护。验证时使用功能状态及控件树，不能单凭黑屏截图判断崩溃。

主密码和恢复码说明见 主密码忘了怎么办.md。手机和桌面各自保管独立密库，没有自动同步。
