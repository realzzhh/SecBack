## 5. 构建与复验注意事项

前端资源嵌入仍要求先更新 `src-tauri/src/lib.rs` 修改时间再编译。编辑 DOM 顺序仍为 head → foot → body，内容区单独滚动，不能破坏顶部操作栏。

本轮旧构建目录的文件替换权限异常，因此使用会话内隔离 Cargo/Android 构建目录。Tauri CLI 完成 arm64 原生编译后，手动复制最新 `.so`，再执行 Gradle，避免打包旧原生输出。Android 插件采用相同版本的缓存源码副本；签名配置沿用原发布证书。

进程内 Java 编译器关闭 R.jar 时出现 AccessDenied，本轮通过 Gradle 初始化脚本启用外部 JDK21 javac 编译完成。没有修改 ACL，也没有把临时构建路径或调试浏览器参数写入产品配置。最终构建验证后仅修改了一条 Rust 说明注释及文档。
