## 六、踩过的坑（省时间，别重踩）

1. **改前端不 `touch src-tauri/src/lib.rs`，改动不进包** —— Tauri 只跟踪 Rust 源。
   表现是"我明明改了，装上去还是老样子"。
2. **密码框聚焦时 `screencap` 全黑** —— MIUI 对密码输入的截屏保护，**不是崩溃**。
   曾经因此白折腾好几轮，以为 WebView 挂了。收键盘后再截就正常。
3. **`adb shell input motionevent` 测不出拖拽** —— 注入的触摸序列会被 WebView 当成点击。
   测长按拖拽要用 CDP `Input.dispatchTouchEvent`（`_cdp_touch.mjs`）。
4. **拖拽松手跳进详情页** —— 真因不是 click（标志位/时间戳/pointer-events 三种都无效），
   而是 `reorder` 后 `render()` → `renderDetail()` 看到 `S.selected` 还有值。
   已用 `wantDetail` 状态修掉，别改回去。
5. **状态栏白条** —— 根因是 Material3 `windowBackground` 默认白色在露底；
   Android 16 起 `windowOptOutEdgeToEdgeEnforcement` 已被移除，不要指望它。
6. **返回键退出 App** —— Tauri `AppPlugin` 的逻辑是"有 `back-button` 监听就只发事件，
   没监听才自己 goBack/退出"。前端必须注册监听并接管，退无可退才调 `plugin:app|exit`。
7. **XML 注释里不能出现 `--`** —— 写 CSS 变量名 `--bg` 会让资源编译直接失败。
8. **弹层 DOM 顺序必须是 head → foot → body**，否则"按钮在顶部"无从谈起。
9. **Tauri 没有主题系统** —— 它只是壳。社区模板全是 Vue/React 整栈，换不动。
   只借设计规范（色板/间距），不引框架。
