# SecBack 0.1.1 界面与发布记录

日期：2026-11-27。界面标识：`20261127-polish-0.1.1`。

## 本次修改

1. 导入预览移除右上角重复的关闭叉号，保留取消与系统返回／Esc 退出路径；开始导入增加下载入库图标，保留原文字、选择预览及防重复提交逻辑。
2. 重新设计应用图标：深墨绿色圆角底、薄荷青绿色锁体和简洁钥匙孔。登录标记、Windows 多尺寸 ICO、Android 启动图标使用同一设计；Android 同时生成自适应前景、背景和单色主题图标。
3. Windows 项目详情改为标题、可滚动正文、底部操作栏三段布局。滚轮只滚动正文，删除／编辑按钮保持在窗口底部，不遮挡正文；编辑按钮使用主题主色。
4. Windows 的文件／外观／帮助改为主题内的图标下拉菜单，深浅配色跟随界面。保留清晰中文名称、分组、操作图标和快捷键提示。支持 F10、Alt+F/V/H、方向键、Home/End、Esc、Tab 与外部点击关闭；锁库时禁用项目操作。继续保留 Windows 系统标题栏、拖动、缩放、最小化／最大化／关闭操作。
5. 产品版本统一为 **0.1.1**，Android 安装升级序号递增至 **1000002**。构建脚本继续自动生成包含版本号的文件名。

## 设计与维护

图标源为 `src/assets/app-icon.svg`；Android 的独立源及配置位于 `src-tauri/icons/`。执行 `npm run icons:generate` 生成各平台尺寸；无需外部在线服务。`build.rs` 跟踪前端和图标目录变动，避免仅改界面或图标时仍打入旧资源。使用隔离 Android 构建目录时，交付脚本会先同步权威工程的资源。

Windows 主题菜单替代旧菜单栏，仍沿用现有消息协议执行新增、删除、导入、导出、改密、恢复码、锁定和关于操作；退出通过宿主执行。其他桌面目标的原生菜单保持原实现。
