# Git 提交范围说明

日期：2026-11-27；整理版本：0.1.1。

| 分类 | 文件或目录 | 本次处理 |
| --- | --- | --- |
| 产品源码 | core、src、src-tauri/src、build.rs、tauri.conf.json | 提交 |
| Android 工程 | gen/android 下 Gradle 配置、wrapper properties、Manifest、Kotlin、主题与 XML 规则 | 提交；gen/android 不能整体忽略 |
| 产品图标 | src/assets、src-tauri/icons（含多平台尺寸）、Android mipmap | 提交；属于构建必需资源 |
| 依赖与版本 | package.json、package-lock.json、Cargo.toml、Cargo.lock | 提交，保持可重复构建 |
| 验证与维护 | tests、core/examples、scripts、.github/workflows | 提交 |
| 文档 | README、docs 及 docs/archive | 提交；归档用于保留被精简说明的历史 |
| 配置模板 | delivery/secback.cfg（全部注释，无真实配置） | 继续跟踪 |
| 安装包与交付清单 | delivery 中 APK、EXE、*.manifest.json | 忽略；旧已跟踪 APK 仅从索引移除，磁盘文件保留 |
| 本机个人脚本 | 清理剩余构建缓存.ps1 | 忽略并保留 |
| 缓存与本机依赖 | target、node_modules、Gradle build/.gradle、jniLibs、自动 schema、local.properties | 不提交 |
| 敏感文件 | keystore、签名配置、真实 secback.cfg、密库／备份、调试日志 | 不提交 |

Git 对中文路径显示的反斜杠数字是路径转义，不是文件损坏。可用 `git -c core.quotePath=false status` 临时显示中文，无需改全局设置。

本轮仅创建本地提交，不执行 push，不删除安装包，也不重写历史。此前在提交前构建的 APK manifest 仍保留其真实构建状态 sourceDirty=true，不伪造为本次干净提交产物。
