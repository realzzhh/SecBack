# SecBack 0.1.0 界面与发布记录

日期：2026-11-26。界面标识：`20261126-theme-0.1.0`。

## 界面变化

- 账户详情的显示/隐藏改为眼睛图标，复制改为双页图标。隐藏时闭眼、可见时睁眼，保留中文可访问名称和桌面悬停提示；手机操作范围为 44×44px。
- 编辑、删除、保存、取消和进入按钮添加统一线性图标并保留文字。登录状态切换为“创建密库”时也保留图标。
- 统一深浅主题：深灰表面、低饱和青绿主操作、中性灰次要操作、柔和红色危险操作。使用共用主题变量，移除后段重复配色覆盖；主操作和取消/删除按钮的正文对比度检查达到 4.5:1。
- 主密码眼睛按钮位于输入框内右侧；打开登录页、切到后台时恢复遮盖。首次建库的确认密码仍随同一开关显示/隐藏。
- 窄屏账户标题和“已设置密码”标签保持单行。

## 版本与命名规则

显示版本统一为 **0.1.0**：package.json、npm lockfile、Tauri 宿主 Cargo.toml/Cargo.lock、Android versionName 和关于信息保持一致。核心库采用独立版本。

Android 安装序号独立设置为 **1000001**，高于已有 1.0.0 调试包的 1000000，允许保留数据直接覆盖安装。今后发布时增加 package.json 的 androidVersionCode，不能跟随显示版本降低。

- `npm run build:windows`：交付 `delivery/SecBack-<version>-Windows-x64.exe`。
- `npm run build:android`：交付 `delivery/android/SecBack-<version>-Android-arm64.apk` 及对应 manifest。
- Windows 调试构建可传 `-- --debug`，文件名增加 `-debug` 后缀。
- 编译器内部的 secback.exe、Gradle 内部 APK 名称保持工具默认；交付脚本读取产品版本生成对外使用的文件名。

本次正式文件名为 `SecBack-0.1.0-Windows-x64.exe` 和 `SecBack-0.1.0-Android-arm64.apk`。旧的无版本号成品属于历史文件。

## 验证

`tests/theme-ui.mjs` 在 393×851、393×420、1000×680 的深浅主题中完成 102 项检查，覆盖图标点击后的复制/显示/进入消息、主密码状态、图标位置、触摸范围、动态文字和颜色对比度。原有 P1 13 项、P2 20 项及其布局检查通过；持续拖动到首尾的三种视口回归通过。截图使用虚构账号检查。

Android 与 Windows 均通过正式构建；Android 继续校验原生库、ABI、签名、版本和安装序号。交付文件的实际哈希、真机覆盖安装和 Windows 正式版启动结果记录在随包 `SecBack-0.1.0-release.json` 中。
