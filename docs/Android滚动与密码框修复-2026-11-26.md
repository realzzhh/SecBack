# Android 滚动与密码框修复记录

日期：2026-11-26。当前界面标识：`20261126-mobile-scroll-r3`。Android 与 Windows 均已重新构建，版本号仍为 1.0.0。

## r3 图标状态调整

按反馈交换眼睛图标：密码不可见时闭眼，可见时睁眼。按钮的中文操作名称仍随点击动作切换。已在重新编译的 WebView 中验证默认隐藏、显示、再次隐藏和进入后台四种状态；下述完整滚动回归于 r2 完成。

## 修改内容

| 问题 | 原因与处理 |
| --- | --- |
| 排序拖到底部后列表无限增长 | 被拖项目的 transform 没有边界，产生额外可滚动溢出；自动滚动又继续推动它。现在在排序开始时记录真实内容的滚动上限和首尾行边界，同时限制项目位移与自动滚动，按实际行高判断换位。排序期间完整测量离屏行，避免预估行高改变边界。 |
| 列表底栏会滚出屏幕 | 根页面固定在视口内，主布局和侧栏限制溢出，列表独立滚动；窄屏主布局跟随实际可视高度。底栏在列表滚动区之外。 |
| 详情删除、编辑栏会滚出屏幕 | 详情改为标题、正文、操作栏三段布局，仅正文滚动。操作栏占据独立空间，取消原先交叠的 sticky/fixed 定位规则。 |
| 密码框小锁偏下、显示按钮占位 | 输入框内右侧改用眼睛按钮，左右图标均以输入框中心定位，按钮不再占据额外的文本行。保留 44px 触摸范围、中文可访问名称与按下状态；进入后台时同步恢复遮盖和图标状态。 |

保留编辑器 `head → foot → body` 顺序、顶部保存/取消、项目信息与账户面板。未引入前端框架。

涉及源码：`src/app.js`、`src/style.css`、`src/index.html`；新增回归脚本 `tests/mobile-scroll-ui.mjs`。
