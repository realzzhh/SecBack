|---|---|---|

| 复制用户名或密码 | 系统剪贴板 | ClipboardManager，标记敏感内容 |
| 加密备份导出并回读校验 | 系统文件保存对话框 | 系统文档创建界面 |

| 恢复码、改主密码 | 支持 | 支持 |
| 自动锁定 | 默认闲置 5 分钟 | 闲置及后台锁定 |
| 单实例 | 支持 | 系统应用实例 |
| 截图和最近任务保护 | 无应用级防截图保证 | 主窗口 FLAG_SECURE |
| 系统云备份/设备迁移 | 不适用 | 明确关闭并排除应用数据 |

## 数据与安全边界

- 密库最多 100000 项，每项固定三套账户；单字段最多 1 MiB UTF-8，序列化明文最多 64 MiB。达到上限时保存拒绝并保留草稿。
- 初次建库与设置新主密码要求 6～1024 个字符；旧短密码仍可登录。主密码可包含字母与符号，不强制数字键盘。
- 五次连续认证失败后开始宿主冷却，逐步增加到 60 秒；应用重启重置进程内计数。离线文件不受界面冷却保护。
- 剪贴板清除只针对本应用仍拥有的内容。桌面约 60 秒后检查；Android 前台计时及离开时尝试清理，后台调度和权限限制下不承诺固定时间必然清除。系统或其他应用已读取的副本无法追回。
- Rust 对主模型、临时密钥和明文缓冲做尽力擦除；JS 和 WebView/System clipboard 内存无法提供物理归零保证。
- 加密版本备份与原库处于同一目录，只解决部分误操作和覆盖问题；不能代替独立导出。备份可能仍接受旧凭据，请同等保护。
- 并发保护依赖本应用遵守锁文件协议，并在保存前比对文件 SHA-256；外部程序完全不遵守锁协议仍可能制造竞争窗口。
- 临时文件写入、同步和原子替换可降低中途失败风险；Unix 父目录同步为尽力执行，不承诺所有文件系统、网络共享或断电情形均耐久。
