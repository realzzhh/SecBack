## 保留的边界

- Android content URI 外部库导入与手机内卸载恢复仍待独立实现；本批完成明确反馈，不将其列为已实现导入。
- 手机导出的加密文件可由桌面读取；恢复码只解决凭据遗忘，不找回被删除的文件。
- Android 剪贴板清除为前台计时/离开时尽力执行，后台不保证固定 60 秒执行。仅清自己的内容，不能追回其他应用或系统已取得的副本。
- 应用私有数据被备份规则排除，不代表恶意系统、root 或第三方服务绝对无法访问。
- 并发保护约束遵守锁协议的写入者，并检测保存前的文件变化；无法保证任意不遵守协议的外部工具之间没有竞争。
- 原子替换与尽力父目录同步不等于所有文件系统的断电耐久保证。
- JavaScript 无法保证明文物理归零；编辑、显示、剪贴板涉及临时明文。
- 本次以 K90 / Android 17 和 Windows 验证；其他 Android 厂商版本、字体/辅助功能组合仍需补充。
- 保留历史已跟踪 APK 的本地交付约定，本轮没有改写 Git 历史，也未对外推送或发布。
