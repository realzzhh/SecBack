# 实现与兼容性

当前结构为独立 Rust 核心 + Tauri 宿主 + 原生 HTML/CSS/JS，共享 Windows/Android 业务逻辑。

v1 保留与 C++ 参考实现的逐字节测试向量，v2 使用 256 字节头和信封加密恢复槽。Rust 支持两种格式；C++ 参考实现不能读取 v2。详见 SecBack_格式契约.md。

Windows 支持外部库预检、解锁、合并预览与写入；同名合并和外部元数据采用均可由用户选择。Android 支持通过系统文件选择器读取外部 content URI 密文，完成预检、输入备份主密码、预览与合并；不导入来源密库的主密码和恢复码设置。

当前能力见 能力与限制.md，构建见 构建与验证.md。2026-11-05 的完整阶段报告保存在 archive/20261125/迁移说明.md，仅供追溯。
