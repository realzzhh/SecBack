## 实现与数据边界

- 使用现有 tauri-plugin-dialog + tauri-plugin-fs，读取 FilePath/content URI 的文件描述符。Android 不按自定义扩展名生成 MIME 过滤，避免合法 .properties 备份被文档提供方隐藏。
- 密文读取上限为 64 MiB + 272 字节；不信任提供方报告的大小，实际读取最多上限 + 1 字节，超限拒绝。
- core 新增 probe_bytes / load_from_bytes。文件路径与文档 URI 统一使用同一套头部校验、长度校验、KDF 限制、AES-GCM 验证和反序列化规则；兼容 v1/v2。
- 导入状态保存的是已选文件的密文快照；预检和解密针对同一批字节，避免两次读取间文件被替换。无明文缓存文件，不保存来源口令；取消、锁定、完成后释放临时状态。
- 系统文件选择器期间保留正常解锁状态，闲置锁定仍有效。读取放到工作线程，URI 解析期间不持 action 锁；回调检查登录会话和请求序号，防止过期结果覆盖当前导入。
- 合并沿用既有事务写入，确认后才改本地库；账户取并集，不传播来源删除。项目名称/备注冲突由用户选择是否采用外部元数据；重复账户不重复添加。
- 导入只合并项目与账户，不替换目标密库的主密码、恢复码或外观设置。新装应用须先创建/解锁目标密库，再导入独立备份。
- 手机导入预览的宽弹层现按视口收缩；关闭、取消、开始导入均保持在屏幕内。编辑器原有 head → foot → body 顺序与顶部操作栏保留。
